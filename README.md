## 프로젝트 배경

코로나 이후 야외활동 수요 증가에 따라 트레킹은 지속가능한 문화관광으로 주목받고 있다. 분 프로젝트는 국립공원 트레킹 코스를 정량적으로 분석해 이용자 맞춤형 추천 시스템을 구축함으로써 문화산업 활성화를 목표로 한다. 이러한 공공 데이터 기반 문화관광 서비스를 통해 K-트레킹 콘텐츠의 전략적 확장 가능성을 제안한다.

## 👤 프로젝트에서 진행한 역할

### 1. 다양한 출처의 데이터 수집·정제

국립공원 탐방로, 음식점, 숙소 등 **다양한 출처의 데이터를 크롤링 및 병합**하였다.

Selenium과 BeautifulSoup을 활용해 각 사이트 구조에 맞춘 크롤러를 설계하고, HTML 파싱 및 좌표 추출을 자동화하였다. 수집된 데이터는 결측치 처리, 좌표 변환, 중복 제거, 포맷 표준화를 포함한 **데이터 클린징 프로세스**를 거쳐 분석 가능한 통합 데이터셋으로 구축하였다.

### 2. KMeans 기반 트레킹 코스 유형화

정제된 데이터를 바탕으로 **KMeans 클러스터링을 수행**하여 트레킹 코스를 5가지 테마로 유형화하였다. Silhouette Score를 사용하여 최적 클러스터 개수를 검증하고, 각 유형별 특징(거리, 난이도, 주변 인프라)을 분석하였다. 이 과정에서 거리·시간뿐만 아니라 **주변 인프라 데이터까지 고려한 다차원 특성 벡터**를 설계하였다.

### 3. 개인 맞춤형 추천 알고리즘 구현

사용자의 선호도(코스 길이, 난이도, 주변 시설 여부 등)와 유형화된 코스 데이터를 매핑하여 **맞춤형 추천 로직**을 구현하였다. 향후 공공·민간·글로벌 데이터와의 융합 가능성을 검증하기 위해, 데이터 스키마와 추천 알고리즘 구조를 확장 가능한 형태로 설계하였다.

## 💡프로젝트 내 회고

이번 프로젝트를 통해 **공공데이터와 민간데이터를 융합한 추천 시스템의 경쟁력**을 실감할 수 있었다.

단순히 거리·시간 기반의 추천에 그치지 않고, 코스 주변 인프라와 사용자의 성향을 반영한 복합적인 추천 로직의 필요성을 확인했다.

데이터 수집 단계에서 다양한 형식과 품질을 가진 데이터를 통합하는 과정은 까다로웠지만, 이를 통해 **데이터 표준화와 품질 관리의 중요성**을 실무적으로 경험할 수 있었다.

또한, 이번 작업을 통해 국내 관광자원을 글로벌 시장에 맞게 패키징할 수 있는 **데이터 기반 전략 수립의 가능성**을 확인했으며, 앞으로 다른 관광·문화 분야에도 이 접근 방식을 확장 적용해보고 싶다는 동기를 얻었다.
